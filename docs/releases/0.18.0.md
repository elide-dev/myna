# Myna 0.18.0

This release makes generated AOT FFM bindings match or beat handwritten ones, gates that with
paired performance checks, and widens what Truffle cells and ownership declarations can describe:
creates that report a status, nullable borrowed buffers, and borrows held by the resource a create
makes.

## FFM performance

- Library bindings hold each symbol address in a nullable `MemorySegment` instead of an
  `Optional`. Typed critical calls went from 1.60 to 1.39 ns/call, level with a handwritten
  object holding the same segment (1.41). A missing symbol still throws `UnsatisfiedLinkError`.
- Static entries skip the per-call class-initialization checks and scope dispatch: the
  descriptor-only outer class initializes at build time, and each entry passes its
  `loaderLookup` address as `MemorySegment.ofAddress`. They now beat a handwritten unbound handle
  (4.82 against 5.56 ns/call on Linux x86-64).
- Static entries for binding ABI 2 native leaves are critical downcalls (0.964 against 1.392
  ns/call for a handwritten critical handle). FFM Truffle cells over leaf imports call them and
  dropped from 5.83 to 1.60 ns/call, level with native cells. Imports that can block or call back
  keep declaring `native_leaf=false@explicit_contract`.
- `benchmarks/gate.py` pairs every generated binding with its matched handwritten or direct call,
  in fresh processes interleaved on the controlled x86-64 host, and fails a pair more than 2% and
  consistently slower. A pair with a known, explained gap carries its own allowance.

All figures are from the controlled x86-64 host (AMD Ryzen Threadripper PRO 9965WX, five
processes per case).

## Truffle cells

- **Creates that report a status and write their handle.** `handle=PARAMETER.FIELD` reads the
  resource pointer from a field of the struct a parameter points to; `handle=PARAMETER` makes that
  struct the resource, initialized in place. `success=N[,N…]` lists the results that mean the
  resource exists; any other raises `NativeStatusException`, which carries the status. The native
  side writes only runtime-owned memory, which the cell copies to the guest's buffer after the
  call, so guest code cannot race the handle or free a resource's struct. Truffle cells only.
- **Borrows held by the resource a create makes.** `borrow … lifetime=resource:NAME` hands the
  buffer to the new resource on success and releases it exactly once after the resource's destroy,
  however the resource dies; on failure it is released at once. `NativeBytes` are lent in place;
  heap arrays and strings are copied rather than pinned. The buffer must be read-only and not
  `nocapture`, on a create with `handle=`. Other backends keep the function's raw binding.
- **Create cells no longer allocate from an automatic arena.** The runtime's struct is `calloc`ed
  and freed explicitly. On the controlled x86-64 host a create and release through a cell costs
  41–45 ns, against 21 ns for the direct call; with the arena the same cases took 291–427 ns on an
  Apple M5 Max.
- **FFM cells check the scope of segments lent in place.** A buffer lent from a scoped segment
  reaches the downcall as that segment, so a closed segment or one owned by another thread is
  refused and a shared arena stays open during the call. Global memory keeps the unchecked
  address path; the paired gates hold every case to its direct call.
- Non-ASCII Java strings and `TruffleString` arguments are lent without making a Java string or
  array: a guest string with 3-byte characters went from 37.4 ns and 32 B to 23.2 ns and 0 B per
  call.
- A pointer to a declared resource takes only an owner of that resource, and any other pointer
  parameter rejects a resource owner. A function that takes a resource as an opaque handle should
  type the parameter `ptr<Resource>`.
- Closing a resource from compiled code no longer fails to compile ("Too deep inlining").

## Ownership declarations

- A borrowed `ptr<u8>` may be `nullable=true`: an absent buffer reaches native code as the null
  pointer with length zero in every wrapper, and a present one, empty or not, is never at the null
  address.

Output for seams that use none of the new forms is unchanged apart from the generator version and
the FFM binding changes above.

The generator version changes every fingerprint; regenerate matching outputs together and
rebuild native libraries against them. Binding ABI 2 and native value ABI v3 are unchanged.
No existing published artifacts or tags are replaced.
