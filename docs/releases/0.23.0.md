# Myna 0.23.0

This release adds direct SVM upcalls for runtime-selected Java callbacks and
generated upcall cells for Truffle. It uses Elide GraalVM and Truffle
25.5.5-elide.33, as do Myna 0.22.0 and 0.21.0. Regenerate and recompile
bindings together to pick up the new generator version and ABI fingerprints.

## Receiver-bound SVM upcalls

Generated callback factories expose `createDirect` for callbacks that native
code invokes repeatedly. The factory binds the Java receiver and, for status
returns, its failure sentinel. The native function pointer keeps the declared
C signature. The arena owns the registration. The shared `create` path
remains available for workloads that prioritize registration cost.

## Truffle upcall cells

A signed `i64` callback can opt in with `truffle_upcall=true` in a module
with `truffle_cells=true`. The generated factory binds a guest call target to
the receiver-bound callback. See [native callbacks into a guest](../truffle-cells.md#native-callbacks-into-a-guest)
for context entry on caller and worker threads and registration lifetime.

The benchmark cycle includes receiver-bound callbacks into compiled Truffle.
The [benchmark guide](../benchmarking.md#upcall-benchmark-cycle) describes the
shared and direct paths, the uninstrumented NFI control, and the retained
samples. The [record batch benchmark](../../benchmarks/upcall-records/README.md)
measures callbacks over borrowed TruffleData records.
