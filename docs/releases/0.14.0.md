# Myna 0.14.0

This release collects correctness fixes for the generators and Truffle cells, and moves the
pinned Elide GraalVM to 25.5.5-elide.28.

## ABI class

- The C `char` signedness is now part of the target ABI class
  ([#71](https://github.com/elide-dev/myna/pull/71)). x86-64 and Apple arm64 (signed `char`)
  keep sharing one LP64 little-endian class; `aarch64-unknown-linux-gnu` (AAPCS64 Linux,
  unsigned `char`) is its own class, recorded as `"charUnsigned":true` in `seam.json`'s
  `targetAbi`. Truffle cells coerce and convert `char` with the target's signedness.
  aarch64 Linux therefore has its own fingerprint; a project publishing for it alongside
  other targets needs a separate set of bindings, and `myna validate --targets` reports the
  split.

## Generator fixes

- `seam.h` declares the `<symbol>_myna_ref` reference prototype for by-value record imports,
  the symbol Native Image binds, so C providers have the same complete contract as Rust
  providers ([#65](https://github.com/elide-dev/myna/issues/65),
  [#70](https://github.com/elide-dev/myna/pull/70)).
- Generated `native-image.properties` initializes `$Literals` at build time, so modules with
  callback exports build through the automatic metadata path
  ([#73](https://github.com/elide-dev/myna/pull/73)).
- The validator rejects the reserved Rust keywords `box`, `become`, `override`, `priv`,
  `typeof`, `unsized` and `gen` as identifiers instead of emitting uncompilable `seam.rs`
  ([#79](https://github.com/elide-dev/myna/pull/79)).
- The validator rejects `isolate_thread` parameters on Truffle cells, which previously crashed
  cell generation ([#89](https://github.com/elide-dev/myna/pull/89)).
- Generated ownership wrappers pin arrays with `try`/`finally` instead of try-with-resources,
  whose `Throwable.addSuppressed` Truffle's runtime-compilation blocklist rejects on partially
  evaluated paths ([#87](https://github.com/elide-dev/myna/issues/87),
  [#95](https://github.com/elide-dev/myna/pull/95)).
- Truffle provider-only facts no longer leak into `seam.ll` as invalid LLVM attributes, which
  broke `myna apply` ([#75](https://github.com/elide-dev/myna/issues/75)).

## Truffle cells

- Foreign interop buffers lent to C-string parameters are NUL-terminated. Previously a
  NUL-scanning callee could read past the borrowed copy
  ([#64](https://github.com/elide-dev/myna/issues/64),
  [#69](https://github.com/elide-dev/myna/pull/69)).
- Big integers wrap to non-`u64` carriers under the `WRAP` coercion policy
  ([#67](https://github.com/elide-dev/myna/issues/67),
  [#72](https://github.com/elide-dev/myna/pull/72)).
- Host `null` arguments raise `NativeCellException` for scalars and pass as null to nullable
  pointers, instead of escaping as a host `NullPointerException`
  ([#76](https://github.com/elide-dev/myna/issues/76)).
- A shared resource closed concurrently with pointer coercion raises the guest-visible
  closed-resource error instead of an internal VM error
  ([#78](https://github.com/elide-dev/myna/issues/78),
  [#80](https://github.com/elide-dev/myna/pull/80)).
- Untrusted guest buffers are reported as guest errors instead of internal failures: a negative
  buffer size, a buffer shrunk or detached before write-back (the surviving bytes are still written
  back), and a shared resource closed during `BytesCoercion` (the counterpart of #80's pointer fix)
  ([#89](https://github.com/elide-dev/myna/pull/89)).

## Truffle cell performance

- Small string and byte-array arguments are copied into a per-thread scratch stack instead of a
  confined arena per call: about 10 ns and 136 B less per copying call on Apple silicon. Copies
  are released last-in, first-out; oversize copies keep the arena path. Each thread that copies,
  virtual threads included, holds a 4–64 KiB block until it is unreachable
  ([#85](https://github.com/elide-dev/myna/issues/85),
  [#91](https://github.com/elide-dev/myna/pull/91)).
- `NativeCell` has typed `executeLong`, `executeInt`, `executeDouble` and `executeBoolean`;
  scalar-result cells override them, which removes the result box on FFM cells (48 → 32 B per
  call) ([#91](https://github.com/elide-dev/myna/pull/91)).

## Values

- The C++ builder's long-text append no longer converts `char` to `uint8_t` implicitly; the same
  bytes are copied ([#89](https://github.com/elide-dev/myna/pull/89)).

## Testing

- Untrusted input is now fuzzed and sanitized
  ([#89](https://github.com/elide-dev/myna/pull/89)):
  - the C++ value fuzzer feeds arbitrary bytes into strings, borrowed regions and number tokens;
  - UBSan's integer and implicit-conversion checks are on, each with an expected-failure canary;
  - the Rust tape reader has a cargo-fuzz target under ASan, property tests against a safe model,
    and Miri;
  - a `.seam` mutation fuzzer runs over the parser and validator.

  `MYNA_SKIP_MIRI_FUZZ=1` skips the Miri and Rust fuzz lanes locally; CI always runs them.

## Toolchain

- Elide GraalVM 25.5.5-elide.28 (checksum-pinned distribution and Truffle/SDK jars). Relevant
  fixes include runtime-initialized classes in runtime-compiled code (graal#217), shared arena
  session checks after calls in scoped accesses (graal#224) and specialized downcall handles
  only when runtime compilation is configured (graal#213).
- Rust is pinned to elide-dev/toolchain's recommended `nightly-2026-10-09` (LLVM 23.1.3), and
  `check:style` fails if the pin diverges from the toolchain bundle or rustc's LLVM is newer than
  the bundle's ([#88](https://github.com/elide-dev/myna/pull/88)).

The generator version changes every fingerprint; regenerate matching outputs together and
rebuild native libraries against them. Binding ABI 2 and native value ABI v3 are unchanged.
No existing published artifacts or tags are replaced.
