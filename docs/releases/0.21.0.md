# Myna 0.21.0

Myna now targets Elide GraalVM 25.5.5-elide.32. Native Image builds use the external
driver, and Truffle dependencies use the matching release. Regenerate bindings to
pick up the new generator version and descriptor fingerprints.

## Bindings and ownership

- The generator can emit standalone Java constants with `--constants-only PACKAGE`.
- An in-place resource can declare a reuse import. A successful replacement preserves
  the owner. If the provider consumes the old contents and reports failure, the owner
  becomes invalid and cleanup releases the backing storage.
- Truffle cells check the lifetime and thread accessibility of scoped native bytes
  before passing their addresses to native code.
- Rust callers can use typed C variadic imports. Generated C headers order dependent
  callback types and support delegated Native Image headers.

## Upcalls

A fixed void callback can declare `ffm_java` and use the generated `create(arena)`
factory to select a direct Native Image upcall stub. The SVM benchmarks cover
dynamic and static callbacks, explicit isolate-thread entry, registration, and
native callbacks into a compiled Truffle guest on caller and worker threads.
See the [benchmark guide](../benchmarking.md#upcall-benchmark-cycle) for commands and
measurement boundaries.
