# Myna 0.17.0

This release finishes the Native Image side of the Truffle cell work begun in 0.16.0 and widens
what ownership declarations can describe.

## Truffle cells

- A cell's `execute` called from host code in a Native Image no longer allocates its borrows. In
  0.16.0 only runtime-compiled callers and `invoke` were free of them; host code, which is compiled
  ahead of time, still paid 48 bytes per byte parameter, because the coercion called itself to
  record a new kind of value and the second `Borrow` merged with the first. The same change
  restores 0.15.0's allocation on HotSpot under the Graal JIT; under C2 the borrow is still
  allocated once several cells share a process.
- ASCII strings are written straight onto the per-thread scratch stack, with no UTF-8 array: an
  11-byte string lent to a C string parameter went from 17.6 ns and 24 B to 15.4 ns and 0 B per
  call (one shared Apple M5 Max, advisory). Text with other characters is encoded into an array
  as before.
- `truffle_buffer=true@explicit_contract` on an import's byte pointer lends raw bytes: no
  terminating NUL, and a heap array pinned when it reaches the pin threshold instead of copied.
  Without it a byte pointer that is not a `borrow` is a C string parameter, copied whole with a
  terminator on every call. The count stays a guest argument, so the guest vouches for it. The
  fact is fingerprinted and is not an LLVM attribute.
- A resource created from another one holds it open. Closing a parent while a resource created
  from it is still open raises `NativeCellException` and leaves the parent open; it closes
  normally once its dependents have. A pointer parameter declared `nocapture` is not held.

## Ownership declarations

- A function may declare several `borrow`s, each with a buffer and a length of its own, and may
  take other pointer parameters, which pass through every wrapper unchanged under their own
  declared contracts. The Rust wrapper is `unsafe fn` when a pointer sits beside its buffers and
  stays a safe `fn` otherwise.
- A borrowed buffer may be write-only (`access=write`); it is lent exactly like a read-write one.
- A resource `create` may take pointer parameters as well as scalars. It must still return
  `ptr<resource>`, null meaning failure. In the Native Image, FFM and Rust wrappers a parent
  resource's lifetime remains the consumer's to enforce.
- Still rejected: a pointer result beside a borrow, one length shared by two buffers, nullable or
  length-less buffers, and creates that return a status and write their handle through an
  out-parameter.

Output for seams that use none of the new forms is unchanged apart from the generator version.

The generator version changes every fingerprint; regenerate matching outputs together and
rebuild native libraries against them. Binding ABI 2 and native value ABI v3 are unchanged.
No existing published artifacts or tags are replaced.
