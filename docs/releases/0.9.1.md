# Myna 0.9.1

Myna now applies contracts to ELF FatLTO objects and their members inside regular `.a`/`.rlib` archives. Version 0.9.0 rejected their embedded `.llvm.lto` sections, preventing use with FatLTO sysroot libraries.

The applicator rewrites embedded IR, rebuilds summaries and hashes, and preserves ThinLTO/full-LTO mode. Native fallback sections, symbols and relocations remain unchanged. Mixed archives retain their member names and order and receive a rebuilt symbol index. Invalid payloads, incompatible contracts and duplicate LTO sections fail before replacing output.

The pinned toolchain is now elide-dev/toolchain 2026.11.2. On Linux, its `-flto` links select FatLTO archive bitcode by default. Non-LTO links retain the native fallback; Myna contracts affect the LTO representation only.

Regenerate matching seam outputs together: the 0.9.1 generator version changes canonical descriptor fingerprints. Binding ABI 2 and native value ABI v3 are unchanged.

Regression coverage includes real ThinLTO and full-LTO ELF containers, mixed archives, idempotence, unchanged native fallback bytes, malformed-input recovery, and Linux link/run tests against generated fixtures and the shipped sysroot archive. See the [LTO integration guide](https://github.com/elide-dev/myna/blob/v0.9.1/docs/thinlto.md).
