# Myna 0.22.0

Regenerate and recompile bindings to use these accessor additions. Myna 0.21.0
provides the preceding generator and the same pinned GraalVM .32 toolchain.

- A declared flag range emits a width literal beside its shift and mask in C,
  Rust, Java and Truffle. A descriptor that already uses the derived width name
  in the same flag set must rename that member before regenerating.
- Native Image field-address methods for pointer slots that previously returned
  `PointerBase` return `WordPointer`, allowing a caller to read the stored word.
  C string pointer slots keep their specialized carrier. Recompile Java callers
  together with their generated bindings because the method descriptor changes.
- Generated Rust persisted-node indexes, reader byte-slice accessors, ownership
  borrows, borrowed pointer getters, and batch length and emptiness queries
  support const evaluation. The generated enum and flag operations remain const.

Use the generator version matching your checked-in descriptors and fingerprints.
