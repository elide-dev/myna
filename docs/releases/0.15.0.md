# Myna 0.15.0

This release moves the pinned native toolchain to elide-dev/toolchain 2026.11.6. Myna's code is
unchanged from 0.14.0 apart from the generator version.

## Toolchain

- elide-dev/toolchain 2026.11.6 for C/C++, LLVM/LLD and the sanitizer configurations, in `mise`,
  CI and the container image. The container image pins the release archives by SHA-256; the
  archives match the published checksums and carry Sigstore build provenance from the
  toolchain's isolated release workflow (`job.release-build.yml`), which verifies with
  `gh attestation verify --repo elide-dev/toolchain`.
- The toolchain's recommended Rust pin is unchanged (`nightly-2026-10-09`), so Myna's Rust pin
  and its drift check stay as they are.

The generator version changes every fingerprint; regenerate matching outputs together and
rebuild native libraries against them. Binding ABI 2 and native value ABI v3 are unchanged.
No existing published artifacts or tags are replaced.
