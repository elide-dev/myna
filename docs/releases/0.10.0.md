# Myna 0.10.0

Native value ABI v3 now supports opt-in IEEE-754 NaN and positive/negative infinity for YAML and other non-JSON producers. Rust Document/Builder and C++ value_builder can set descriptor flag bit 0; both Java native readers honor it. Finite-only defaults, strict decimal tokens, descriptor layouts, allocator ownership and poisoned-builder recovery remain unchanged. Older readers safely reject flagged descriptors. See [value API documentation](https://github.com/elide-dev/myna/blob/v0.10.0/docs/values.md).

This release adds enforced Java/C++/Rust formatting, strict Java and LLVM warnings, Clang security analysis, stronger malformed-input regression coverage, and deterministic JAR/SDK packaging. Native build wrappers honor caller compiler and flag overrides. The README now includes the live OpenSSF Best Practices badge, with governance, security-response and assurance documentation supporting the silver application.

Regenerate matching seam outputs together: generator version 0.10.0 changes canonical descriptor fingerprints. Binding ABI 2 and value ABI v3 remain unchanged. New non-finite values require upgraded producers and readers.

Validation includes Rust and JVM tests, C++ sanitizer tests, expected-failure sanitizer canaries, LLVM integration/coverage, and real Native Image execution through both value readers. No changes to previously published artifacts or tags.
