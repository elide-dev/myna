# Myna 0.11.0

This release adds opt-in value ABI v4 for producer-neutral aliases, per-node
metadata, and indexed object lookup. Default Rust and C++ producers retain ABI
v3; Java readers support v2, v3, and v4. Existing v3 descriptor layouts are
unchanged. Enable v4 explicitly and pass its complete 88-byte descriptor.

- Object directories use a shared FNV-1a UTF-8 hash and preserve first-match
  semantics for duplicates and hash collisions.
- References name completed earlier subtrees. Readers expose targets explicitly;
  they never expand aliases automatically. Metadata IDs remain format-specific.
- C++ builders can reserve nodes, bytes, regions, and container depth, retain
  capacity across clear/reuse, and preserve allocator and poison contracts.
- Native readers can rebind between messages. Checked kind/key helpers and
  prepared-key word/hash accessors support partially evaluated callers.
- Batch text export converts keys, strings, and exact number tokens into shared
  caller-owned Latin-1/UTF-16LE storage and a per-node index table.
- SIMD crossover is configurable per reader. The default remains 256 bytes;
  the expanded benchmark retains raw samples and build/hardware metadata.

Builds use elide-dev/toolchain 2026.11.5. No existing published artifacts or tags
are replaced. See [value API contracts](../values.md) and
[text benchmark instructions](../../benchmarks/text/README.md).
